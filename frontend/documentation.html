Getting Started

Quick Start

  1. Enter battery parameters (Voltage, Temperature, Capacity, Cycles)
  2. Click "EXECUTE PREDICTION" to analyze battery health
  3. View SoH percentage, RUL, and degradation analysis
  4. Navigate to other sections for detailed insights

Input Parameters

Voltage (V): Battery voltage, acceptable range 3.4V - 3.7V

Temperature (°C): Operating temperature, acceptable range 20°C - 45°C

Capacity (Ah): Battery capacity, acceptable range 1.5Ah - 2.2Ah

Charge Cycles: Number of charge/discharge cycles, acceptable range 1 - 167

architecture

Model Architecture

LSTM Neural Network

Input Layer: 50 time steps × 4 features

LSTM Layers: 128 → 64 → 32 units with dropout

Dense Layers: 64 → 32 → 1 units with ReLU

Output: Single neuron predicting SoH (0-1 range)

Training: Adam optimizer, MSE loss, 50 epochs

api

API Reference

Prediction API

Endpoint: POST /api/predict

Request Body: {voltage, temperature, capacity, cycles}

Response: {soh, rul, confidence, category, degradation_severity}

Troubleshooting

Common Issues

Prediction Error: Ensure all input fields are filled with valid values

Model Loading: Check that LSTM model files exist in project directory

Navigation Issues: Verify HTML files are in frontend folder
